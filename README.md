## 它能做什麼

- **自動偵測螢幕上的字** — 設定要找的文字和觸發動作（點擊、按鍵、拖曳），找到就自動執行
- **用圖片來找按鈕** — 沒文字的地方，截圖當範本就能比對，速度比看字更快
- **多步驟串成流程** — 偵測→點擊→等待→拖曳…全部自動跑完，像錄好的巨集
- **不同場景切換任務** — 不同遊戲或工作存成獨立檔案，一鍵切換
- **換螢幕也不怕** — 座標自動按比例調整，筆電外接螢幕也不用重設
- **看著畫面設定規則** — 打開 OCR 診斷，畫面上所有文字直接列出來，找到目標按兩下就建立規則，不用量座標也不用查參數

## 快速開始

1. 下載 `ocr-trigger-clicker.zip` → 解壓縮 → 執行 exe
2. 選取目標視窗 → 按「啟動」

詳細引導請看 [快速上手指南](./START.md)。

---

## 系統需求與安裝

- Windows 10 / 11（64 位元）
- 免安裝、免 Python 環境，下載 ZIP 解壓縮直接執行
- 如果遊戲沒反應，試試**按右鍵 → 以系統管理員身分執行**
