## What it does

- **Detect text on screen** — tell it what text to look for and what to do (click, press a key, drag). When found, it acts automatically.
- **Find buttons with images** — no text? Use a screenshot as a template. Faster than reading text.
- **Chain multiple steps** — detect → click → wait → detect → drag… runs all the way through like a recorded macro.
- **Switch between tasks** — save each game or workflow as a separate file. One-click switch.
- **Resolution-proof** — coordinates auto-scale. Plug in a monitor or resize the window — no reconfiguring.

## Quick start

1. Download `ocr-trigger-clicker.zip` → extract → run the exe
2. Select your target window → click "Start"

For step-by-step guidance, see the [Quick Start Guide](./START.en.md).

## System requirements & installation

- Windows 10 / 11 (64-bit)
- No installation or Python needed — download the ZIP, extract, run
- If nothing happens, try **right-click → Run as Administrator**
