## 它能做什么

- **自动检测屏幕上的字** — 设定要找的文字和触发动作（点击、按键、拖拽），找到就自动执行
- **用图片来找按钮** — 没文字的地方，截图当模板就能比对，速度比看字更快
- **多步骤串成流程** — 检测→点击→等待→拖拽…全部自动跑完，像录好的宏
- **不同场景切换任务** — 不同游戏或工作存成独立文件，一键切换
- **换屏幕也不怕** — 坐标自动按比例调整，笔记本外接屏幕也不用重设

## 快速开始

1. 下载 `ocr-trigger-clicker.zip` → 解压 → 执行 exe
2. 选取目标窗口 → 按「启动」

详细引导请看 [快速上手指南](./START.md)。

---

## 系统需求与安装

- Windows 10 / 11（64 位）
- 免安装、免 Python 环境，下载 ZIP 解压直接执行
- 如果游戏没反应，试试**右键 → 以系统管理员身份运行**
