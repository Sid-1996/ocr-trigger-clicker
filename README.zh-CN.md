## 它能做什么

| 功能 | 说明 |
|:----:|------|
| 🔍 | **自动检测屏幕上的字** — 设定要找的文字和触发动作，找到就自动执行 |
| 🖼️ | **用图片来找按钮** — 截图当模板比对，没文字的地方也能用 |
| 🔗 | **多步骤串成流程** — 检测→点击→等待→拖拽…全部自动跑完 |
| 📂 | **不同场景切换任务** — 不同游戏或工作存成独立文件，一键切换 |
| 📐 | **换屏幕也不怕** — 坐标自动按比例调整，外接屏幕不用重设 |
| 👁️ | **看着画面设定规则** — OCR 诊断面板列出所有文字，按两下就建立规则 |
| 🎮 | **后台挂机** — 后台模式用 PrintWindow 截图 + PostMessage 点击，窗口可最小化或遮挡，不抢焦点 |

## 系统需求与安装

- **Windows 10 / 11**（64 位）
- 免安装、免 Python 环境，下载 ZIP 解压直接执行
- 如果游戏没反应，试试 **右键 → 以系统管理员身份运行**
