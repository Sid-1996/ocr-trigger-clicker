OCR Trigger Clicker

免寫程式的 Windows 自動化工具 — 偵測螢幕文字後自動點擊與按鍵。支援繁中 / English UI、ROI 區域設定、圖像比對、多步驟流程。

先選你現在要做什麼

核心功能

一套工具涵蓋文字偵測、圖像比對、流程編排與多任務管理。

🔍

OCR 文字辨識

基於 RapidOCR 引擎，支援繁體中文與簡體中文。可指定 ROI 精確比對，避免全螢幕干擾。

🖼️

圖像模板比對

以圖找圖，支援多尺度搜尋與 NMS 篩選。適合無文字的按鈕或圖示辨識，效能比 OCR 快 10~50 倍。

🔗

多步驟流程

每條規則由有序步驟組成：偵測、點擊、按鍵、等待、跳轉、數值比對、圖像比對、滾輪、拖曳。

📂

多任務管理

不同場景（不同遊戲、不同表單）建立獨立任務，規則完全隔離，一鍵切換。

👁️

OCR 即時診斷

即時顯示目前視窗內所有可辨識文字及其位置與信心度，按兩下直接建立規則。

🛡️

安全與通知

前景保護、系統托盤常駐、on_fail 通知與自動停止群組，長時間運行也安心。

🎬

錄製操作

按 F9 開始錄製，在遊戲裡點擊示範一遍，停止後自動轉成規則——不用一條條手動設定。

使用指引

從下載到啟動，最快 3 分鐘。

快速入門

  1. 下載解壓縮：從 GitHub Releases 下載 ocr-trigger-clicker.zip，解壓縮後執行 ocr-trigger-clicker.exe。
  2. 選目標視窗：在工具列選取你要操控的視窗（遊戲、ERP 系統、瀏覽器等）。
  3. 建立群組：右鍵 → 新增群組。預設是「執行一次」+「依序執行」。
  4. 加規則：在群組內新增規則，第一步選「偵測（detect）」，輸入你要找的文字。
  5. 用 OCR 診斷確認：按「OCR 診斷」確認文字有沒有被偵測到。
  6. 加動作步驟：偵測後面加「點擊（click）」或「按鍵（key）」。
  7. 測試：按「▶測試」確認規則是否正常觸發。OK 就按「啟動」開始跑。
  8. 不想手動設？錄製操作：按「錄製操作」（或 F9）錄一遍點擊示範，停止後自動轉成規則（只記錄滑鼠點擊，盡量點在文字或圖示上效果更好）。

進階技巧

  • 縮小 ROI：偵測區域越小，OCR 速度越快。建議只框選包含目標文字的最小範圍。
  • 加等待：在動作步驟之間加「等待（wait）」，讓畫面有時間變化。
  • 用 jump 跳轉：在規則間跳轉（限同群組內），可實現條件分支流程。
  • 用 compare 做數值判斷：對 ROI 內的數字做大於／小於／等於判斷。
  • 用 match_image 比對圖示：載入範本圖片後框選偵測 ROI，適合無文字的按鈕辨識。
  • 善用常駐監控：勾選「常駐監控」讓規則每幀都跑，適合做錯誤攔截。
  • 用錄製當起點：複雜流程先錄一遍生成規則，再微調偵測文字與點擊位置，比從零開始快很多（點在 UI 文字或圖示上，轉換品質最好）。

工具教學

每個工具都有專屬功能，搭配使用能大幅降低設定難度。

🔍 OCR 診斷面板

即時顯示目標視窗中所有可辨識的文字、位置與信心度。

  1. 按主介面上的「OCR 診斷」按鈕。
  2. 面板開啟後，即時掃描目標視窗，列出所有辨識到的文字。
  3. 點選任一筆文字，可以看到它的位置（ROI）和信心度。
  4. 按「建立為新規則」自動帶入文字和 ROI。

📐 ROI 框選

ROI（Region of Interest）就是你要偵測的畫面範圍。範圍越小，速度越快、準確度越高。

  1. 在偵測步驟中，按「框選偵測區域」按鈕。
  2. 主視窗自動最小化，目標視窗跳到前景。
  3. 在目標視窗上拖曳滑鼠，框選你要偵測的區域。
  4. 放開滑鼠後自動回到主視窗，ROI 座標自動填入。

🖱️ Click Picker（點擊座標選取）

選取你要點擊的精確位置。

  1. 在點擊步驟中，按「選取點擊座標」按鈕。
  2. 主視窗最小化，目標視窗跳到前景。
  3. 在目標視窗上單擊你要點擊的位置。
  4. 自動回到主視窗，座標自動填入。可搭配「隨機偏移」避免被檢測。

🖼️ match_image 圖像比對

以圖找圖，效能約為 OCR 的 10~50 倍，且不受背景文字干擾。建議優先選用。

  1. 在步驟中選擇「match_image（圖像比對）」。
  2. 按「選取範本圖片」載入你要比對的圖片。
  3. 按「框選偵測區域」框選搜尋範圍。
  4. 調整「相似度門檻」：越高越嚴格，建議從 0.7 開始調。
  5. 按「測試比對」確認是否命中。

🧪 乾跑測試（Dry-run）

不實際執行動作，先看規則會發生什麼事。

  1. 選取你要測試的規則。
  2. 按「▶測試」按鈕。偵測步驟會實際截圖辨識，但點擊／按鍵不會真的執行。
  3. 查看結果，根據結果調整參數再測一次。

🎬 錄製操作（示範錄製）

不知道怎麼設定規則？直接錄一遍，工具自動轉成規則——不用一條條手動設定。

  1. 選取目標視窗，按「錄製操作」按鈕（或按 F9）開始錄製。
  2. 在遊戲裡正常點擊要做的事情，錄製期間不搶焦點，可照常操作。
  3. 再按一次 F9（或按「停止」）結束錄製。
  4. 選擇「建立新任務」或「併入既有任務」，每個錄製段會變成一個群組。

⚠️ 本模式只記錄滑鼠點擊（左鍵／右鍵／中鍵）。鍵盤按鍵、拖曳、滾輪不會被錄製——錄製時想「等一下再點」就直接放慢手速，不要按鍵盤。

錄製小技巧：點在「有東西」的地方，轉換品質更好

  • ✅ 點在 UI 文字上方 → 自動轉成「等文字出現再點擊」，畫面縮放／換解析度都不怕，最穩定。
  • ✅ 點在 圖示／按鈕（無文字但有特徵）→ 自動轉成圖示比對（match_image）後點擊。
  • ❌ 點在 空白處 → 只能轉成固定等待後點擊（純計時播放），換解析度或畫面位移後容易點錯位置。

💡 自動轉換：點在文字上 → 等文字出現再點擊；無文字但有圖示 → 圖示比對後點擊；空白處 → 固定等待後點擊。座標一律存為視窗比例，換螢幕／換解析度不用重設。

規則設計原則

理解這三個原則，就能設計出大部分的腳本。

原則一：失敗就跳

規則的步驟從上往下跑，但如果某一步失敗（on_fail 設「停止規則」），整條規則就結束，後面的步驟全部跳過。

所以：動作步驟一定要放在偵測後面，偵測失敗就不會誤觸發。

原則二：等待只在成功後

等待步驟放在偵測後面 → 只有偵測成功才會等待那幾毫秒。偵測失敗 → 等待直接跳過，不會卡住。

這是安全的設計，不用擔心等待會造成卡關。

原則三：背景規則適合攔截型

背景規則每幀都跑，不受群組指標影響。適合做緊急攔截（例如出現錯誤訊息時立刻按掉）。

一般任務放在群組規則就好，不需要勾選「常駐監控」。

原則四：要推進就靠動作步驟

一條規則要「完成並進到下一條」，必須有實體動作步驟（點擊／按鍵／拖曳／滾輪）。如果只放「偵測＋通知(notify)」，規則會一直重複通知、卡在原地。

想做「各自出現就提醒」請改用「常駐監控」，想依序處理就加動作步驟。

常見腳本模式

以下四種模式涵蓋 80% 的使用場景。

模式一：循環任務

偵測到特定文字 → 執行動作 → 等待畫面變化 → 再偵測。重複循環。

detect（文字A）→ click → wait 1000ms → detect（文字B）→ click → wait ...

適用：遊戲日常 farming、表單重複填寫、批次處理。

模式二：錯誤攔截

背景規則每幀檢查，偵測到錯誤訊息就自動按掉。

detect（錯誤訊息）→ click（確認按鈕）

適用：長時間運算時自動處理彈窗、遊戲掉線自動重連。

模式三：數值監控

偵測特定數字，超過／低於門檻就觸發動作。

compare（數值 >= 100）→ click / key

適用：監控遊戲血量、進度百分比、庫存數量。

模式四：圖示比對

無文字時用圖片比對偵測按鈕或圖示。

match_image（範本圖）→ click（匹配位置）

適用：遊戲介面按鈕辨識、無文字的 UI 元素。

腳本設計範例

四個完整範例，從簡單到進階。可以直接複製步驟順序到你的規則中。

範例一：遊戲日常 Farming

偵測到 NPC 對話「要開始了嗎？」→ 按「確定」→ 等 2 秒 → 偵測「任務完成」→ 按「領取獎勵」。

步驟 1: detect「要開始了嗎？」→
步驟 2: click「確定」→
步驟 3: wait 2000ms →
步驟 4: detect「任務完成」→
步驟 5: click「領取獎勵」

群組設定：「執行一次」。完成一輪後手動再按「啟動」，或改「循環執行」自動重複。

範例二：錯誤自動處理

遊戲彈出「連線中斷」視窗，自動按「重新連接」。

步驟 1: detect「連線中斷」→
步驟 2: click「重新連接」

勾選「常駐監控」，讓這條規則每幀都檢查。沒偵測到就跳過，不會卡住。

範例三：血量低於門檻自動喝藥

偵測到血量數字 <= 30% 就自動喝藥。

步驟 1: compare（ROI: 血量區域）數值 <= 30 →
步驟 2: key「F1」（喝藥快捷鍵）

compare 步驟會自動從 ROI 中抓數字。群組設定「循環執行」讓它持續監控。

範例四：偵測圖示按鈕自動點擊

遊戲中出現特定圖示（例如寶箱），自動點擊拾取。

步驟 1: match_image（範本: 寶箱截圖）→
步驟 2: click（匹配位置）

相似度門檻從 0.7 開始調。先用「測試比對」確認命中率再正式啟動。
